# Inkwell — Jot Studio Edition

Alternate UI for the CodeWorks Jot checkpoint. Same MVC + `localStorage` behavior as the classic app, with a warm editorial redesign.

## Run

From the repo root:

```powershell
npm run start:inkwell
```

Open **http://127.0.0.1:8081**

Classic Jot UI: **http://127.0.0.1:8080** (`npm start`)

Data is stored separately (`inkwell_jots` in localStorage).
